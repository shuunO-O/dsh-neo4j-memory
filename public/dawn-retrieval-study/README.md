# 黎明之剑：图谱与向量检索对照

打开 `index.html` 查看研究概览、检索算法、对照结果与逐题复审。页面可离线运行，不需要数据库、模型接口或密钥。

## 实验语料

实验使用《黎明之剑》前 500 章的提取结果：4,648 个事件、人物、地点与概念，33,899 条关系，图节点使用 768 维向量。事件中保留了关联的原文内容；模型提取的摘要、关系和人物对齐仍可能有错误。数据库中的事件时间是用于排序的合成时间，不是故事发生日期。

## 复现范围

本目录只包含页面本身（`index.html`、`app.js`、`style.css`、`data.js`），不包含数据库备份、原文场景向量缓存或模型接口。页面的数字、答案与评分都固化在 `data.js` 中，因此克隆后打开页面即可看到与发布时一致的结果；但仅凭本目录不能重建数据库，也不能重跑检索或对照实验。
