THE MEMORY PIPELINE

历史如何入库

每个人物使用独立的 Neo4j 数据库，按时间顺序回放对话。同一自然日内的多轮用户和助手消息合并为一批，用 Qwen3.8 Flash 一起抽取事件、实体和关系；遇到题目的历史截止点就拆批，抽取失败时也可能拆成更小批次重试。

每批抽取结果经 Qwen3.7 Text Embedding 生成 1024 维向量并写入记忆。本轮六个人物共处理 2,240 轮、851 批；考试题目和答案不写入记忆。

作答时只额外提供最近六轮，由 DeepSeek V4.1 Flash 高思考模式自主检索；每题最多 6 次工具调用，每次最多 10,976 字符，不交付额外候选。完整历史和标准答案不会交给作答模型。
