导入与导出图谱

页面默认读取插件后端当前的 Neo4j 记忆图谱。点击“刷新”可重新读取；显示设置中的节点类型只筛选当前视图。

支持包含 nodes 与 relationships 的 JSON，也支持保存的 记忆图谱接口完整响应。若手头只有 .dump 文件，需要先在独立 Neo4j 实例恢复，再导出为图谱 JSON。

导入仅替换当前浏览器视图，不写回 Neo4j。点击“刷新”或重新打开页面即可返回当前记忆图谱。导出 JSON 可再次导入查看，不能代替数据库备份。

当前支持最多 3,000 个节点、20,000 条关系和 20 MB 的导入文件。超限会提示，不会截断图谱；可通过节点类型减少从 Neo4j 读取的范围。
